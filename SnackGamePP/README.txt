贪吃蛇 SnackGame++ —— 提交说明
================================

一、直接运行（无需安装任何环境）
  双击 SnackPP.exe 即可玩。
  注意：assets 文件夹必须和 exe 放在同一层（本包已保持此结构）。

  首次进入为登录界面：
    注册 —— 输入账号密码后点"注册"，自动登录（支持字母/数字，最长 16 位）
    登录 —— 已有账号直接登录，最高分按账号独立记录
    游客进入 —— 不登录直接玩，最高分存 best.dat

  游戏操作：方向键 / WASD 移动   空格 暂停   回车/R 重开   M 音效开关   Esc 退出
  登录界面：Tab 或点击切换输入框   Enter 登录   密码显示为 *

二、编译源码
  命令行：g++ main.cpp -o SnackPP.exe -mwindows -std=c++11
  Dev C++：新建工程 -> 添加 main.cpp -> 编译运行
  （本程序基于 GameLib，专为 Dev C++ 等零配置环境设计，
    不需要链接 gdi32 等任何库）

三、文件说明
  main.cpp     全部游戏代码（约 400 行）
  GameLib.h    第三方单头文件游戏库（MIT 协议）
               出处：https://github.com/skywind3000/GameLib
  assets/      背景图片
  SnackPP.exe  已编译好的可执行文件（Windows，MinGW g++ 编译）

四、实现功能
  - 账号系统：登录界面（注册/登录/游客），账号存 accounts.txt，
    密码 FNV-1a 哈希存储，最高分按账号独立记录
  - 渐变色蛇身：投影阴影、鳞片描边、上方高光、呼吸脉动
  - 蛇头细节：头顶高光、鼻孔、双眼（白眼球/瞳孔/反光点）、分岔舌头
  - 方向输入队列：快速连按不丢帧、不会误反向导致暴毙
  - 事件音效：吃食物/死亡/胜利/暂停/登录五种（PlayBeep 旋律调度）
  - 最高分持久化：登录用户写账号记录，游客写 best.dat
  - 背景图等比缩放铺满（exe 相对路径定位，启动方式无关）
